# Depression Sensitive Music Recommendation System

## Project Description

This project is a Python-based music recommendation system that identifies
the user's emotional state from their input and recommends suitable songs.

## Objectives

- Detect the user's mood from text input.
- Classify the mood into different emotion categories.
- Recommend songs based on the detected emotion.
- Provide a simple and easy-to-use recommendation system.

## Emotions Supported

- Happy
- Sad
- Angry
- Relaxed
- Neutral

## Technologies Used

- Python
- Natural Language Processing
- Emotion Detection
- Recommendation System
